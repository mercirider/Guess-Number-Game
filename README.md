# 🎯 Guess The Number Game (1-10)

Ek simple, modern aur interactive **number guessing game** jo pure **HTML, CSS aur JavaScript** mein bana hai. Koi framework nahi, koi library nahi — bas ek hi file mein poora game!

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔢 **Numbers 1-10** | Sirf 1 se 10 tak — bade clickable buttons |
| 🎯 **3 Chances** | Har game mein 3 tries milte hain |
| 💡 **Live Hints** | "Bada hai" ya "Chhota hai" ka batata hai |
| 🎨 **Modern UI** | Glassmorphism + gradient design |
| 🎊 **Confetti Animation** | Jeetne pe colorful confetti girta hai |
| 🌈 **Animated Background** | Floating glow circles |
| 📊 **Live Stats** | Range, Chances, Tries — sab live update |
| 🎮 **Color-Coded Feedback** | Yellow = chhota, Blue = bada, Green = sahi |
| 🔄 **Replay Button** | Ek click mein naya game |
| 📱 **Fully Responsive** | Mobile, tablet, laptop — sab pe perfect |
| 🚫 **No Zoom/Scroll** | Har screen pe exact fit |
| ⚡ **Zero Dependencies** | Koi library nahi, pure vanilla JS |
